## ⚙️ 機能
- スライダーおよびスピナーを除く、すべてのヒットオブジェクトの座標を `(256, 192)` に揃えます

## 💡 このツールはなぜ有益なのか？

- **osu!lazer** では、すべてのヒットオブジェクトが常にプレイフィールドの中央に配置されます。
- **osu!stable** では、ヒットオブジェクトは任意の座標に配置することができます。

多くの **Ranked 譜面** は視覚的に中央へ揃えられていますが、  
**osu!stable にはヒットオブジェクトを一括で中央に揃える手段が存在しません**。

## ✨ 特長

- **単一ファイル入力**
  - `.osu` ファイルを1つずつ処理
  - 挙動が明確で予測しやすい設計

- **バッチモード（再帰なし）**
  - 有効にすると、選択したファイルと同じフォルダ内の `.osu` をすべて処理
  - サブフォルダは意図的に処理対象外

- **安全な上書きと自動バックアップ**
  - 一時ファイルを用いた安全な置換方式を採用
  - バックアップは UI から有効 / 無効を切り替え可能

## 🖥 動作環境

- Windows 10 / 11（x64）
- .NET ランタイムのインストール不要（自己完結型ビルド）

## 🚀 使い方

1. `AlignTaiko.exe` を起動します
2. `.osu` ファイルをウィンドウにドラッグ＆ドロップ  
   *または* ドロップエリアをクリックして参照
3. **Single** または **Batch** モードを選択
4. 必要に応じてオプションを調整（バックアップ、言語など）
5. 実行

**Batch モード**では、選択したファイルと同じディレクトリ内の `.osu` がすべて処理されます。

## ⚠️ 注意事項

- **type が 1 または 5 のヒットオブジェクトのみが変更されます**  
  （スライダーおよびスピナーは対象外です）

- サブディレクトリは一切処理されません

- **バックアップフォルダは `.osu` ファイルを含むフォルダ内に生成されます**  
  譜面を upload する際は、必ずこのフォルダを削除してください

- **スライダーの調整は手動で行ってください**  
  このツールはスライダーの形状や制御点を自動で変更しません

- このツールはインターネットや外部サービスへアクセスしません
